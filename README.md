# สมุดบันทึกงาน อ.บอล

เว็บแอปสมุดบันทึกงานภาษาไทย พร้อมแผนงาน เช็กลิสต์ ไดอารี่ รายงาน และหน้าอวยพรวันเกิด

## เปิดใช้งาน

- เว็บ: https://janjankakaka-sudo.github.io/jsrstudio1983-notebook-gift/
- หน้าอวยพร: https://janjankakaka-sudo.github.io/jsrstudio1983-notebook-gift/birthday.html
- ใช้ได้บนมือถือและคอมพิวเตอร์ในเบราว์เซอร์สมัยใหม่

## ฟังก์ชัน

- เพิ่ม แก้ไข และลบแผนงาน พร้อมวันเริ่ม/สิ้นสุด สถานะ และความคืบหน้า
- สร้างเช็กลิสต์ เพิ่ม/ติ๊ก/ลบรายการย่อย
- เขียน แก้ไข และลบบันทึกไดอารี่ พร้อมเลือกอารมณ์และหมวดหมู่
- รายงานย้อนหลัง 7, 30 และ 90 วัน พร้อมส่งออก CSV และพิมพ์/PDF
- สำรองและกู้คืนข้อมูลเป็น JSON, จัดการหมวดหมู่ และตั้งค่าข้อความอวยพร
- หน้าอวยพรมีภาพประกอบ SVG, เสียงดนตรีที่สร้างในเบราว์เซอร์ และปุ่มแชร์/LINE

## การจัดเก็บข้อมูล

ข้อมูลสมุดบันทึกอยู่ใน `localStorage` ของเบราว์เซอร์และอุปกรณ์ที่เปิดเว็บนั้นเท่านั้น ไม่ได้ซิงก์ข้ามอุปกรณ์หรือบันทึกลง GitHub อัตโนมัติ ควรดาวน์โหลดไฟล์สำรองจากเมนู **ตั้งค่า → ดาวน์โหลดข้อมูลสำรอง** เป็นระยะ และเก็บไฟล์ไว้ในที่ปลอดภัย

## GitHub Pages

Repository นี้มี `index.html` อยู่ที่ root ของ branch `main` หากยังไม่เปิดเผยแพร่ ให้ไปที่ **Settings → Pages** แล้วตั้ง Source เป็น **Deploy from a branch**, เลือก `main` และโฟลเดอร์ `/ (root)` จากนั้นบันทึก
